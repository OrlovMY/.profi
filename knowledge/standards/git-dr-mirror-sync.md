# Standard: DR-зеркало git — синхронно в оба remote

**Статус:** обязательный · **Применимость:** любой проект с зеркалом репозитория (disaster recovery).

## Правило
Если у репозитория есть DR-зеркало (второй remote: GitHub↔GitLab и т.п.) — после **каждого** push в основной remote немедленно пушить и в зеркало. «Потом» = окно рассинхрона = потеря при сбое основного хоста.

```
git push <адрес записи> <branch> && git push <зеркало> <branch>
```

- Конкретные remote-URL и имена зеркал — в памяти/доке проекта, НЕ в этом универсальном правиле. **Имя ремоута — псевдоним, а не адрес:** в MDMy `origin` за одни сутки 19.08.2026 сменил назначение с GitLab на GitHub. Поэтому правило называет роли («адрес записи», «зеркало»), а не имена.
- Держать одинаковый набор веток (или явно знать, что зеркалится только основная).

## Приостановка зеркалирования — как она выглядит

Зеркалирование может быть **приостановлено владельцем**, и тогда push в зеркало пропускается, а правило не считается нарушенным. Приостановка обязана быть записана и иметь признак снятия.

**Действует сейчас (MDMy, с 18.08.2026):** писать только в GitHub, в GitLab не писать — прямое указание владельца, `memory/feedback_push_github_only_temporarily.md`. Зеркалирование **приостановлено, а не отменено**: когда владелец разрешит, вернуть двойной push и догнать пропущенное.

```bash
git push <адрес-записи> <branch>
# git push <зеркало-GitLab> <branch>   # ⏳ ПРИОСТАНОВЛЕНО владельцем 18.08.2026;
#                                      #    имя зеркала — из git remote -v, не из памяти
```

Строку не удалять, а держать закомментированной с меткой `⏳` и причиной: удаление потеряет то, что придётся возвращать, и через месяц никто не вспомнит, что зеркало вообще было.

**Насколько разошлось зеркало — измерять, а не предполагать, и измерять после `fetch`:** `git fetch <зеркало> && git rev-list --count <зеркало>/master..master`. Ноль означает, что зеркало догнало. Без `fetch` число говорит о свежести локального ref, а не о состоянии зеркала — 19.08.2026 эти две неисправности дали одинаковый симптом и были разведены только свежим чтением. Конкретную величину здесь не фиксируем: она меняется ежедневно, а правило — нет.

## Зачем
DR-зеркало имеет смысл только синхронным. Рассинхронизированное зеркало создаёт ложное чувство защищённости.
