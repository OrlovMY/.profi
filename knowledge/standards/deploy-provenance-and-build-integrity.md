# Стандарт: deploy-provenance-and-build-integrity

**Статус:** канон (универсально — все компоненты и проекты).
**Происхождение:** вердикт Большой 7, 2026-07-04. Root-cause граблей: vc84-87 stale-builds (номер БЫЛ, но артефакт собран из залипшего worktree → embedded-версия ВРАЛА); integ/build72 — источник задеплоенного кода — жил только локально (риск потери до merge); build72 собирался частичными пакетами.

## Принцип
Задеплоенный артефакт всегда однозначно прослеживается до неизменяемого, запушенного git-ref; версия, вшитая в артефакт, не может врать.

## Правила

1. **Монотонный build-счётчик на компонент.** Номер живёт в git как source-of-truth (versionCode / BUILD в коде), коммитится вместе с изменением, строго растёт каждый релиз. Никакого ручного присвоения номера в момент деплоя.

2. **Единая integ-ветка, merge ДО деплоя.** Все одобренные изменения стекаются в одну integ-ветку и мержатся полностью перед деплоем. **Никаких частичных пакетов** (для OTA — всегда полный пакет всех компонентов; ср. `ota-always-full-package`). Integ-ветка немедленно пушится на все зеркала — не живёт только локально (иначе источник задеплоенного кода можно потерять).

3. **Сборка только из запушенного ref.** Build-скрипты собирают из чистого checkout запушенного git-ref, НЕ из локального/stale worktree. Freshness-guard в скрипте: fail, если рабочее дерево грязное или ref не совпадает с origin.

4. **Artifact↔git checksum-соответствие.** После сборки верифицировать, что версия/build, вшитые в артефакт (versionCode APK, BUILD binary), == коммиту, из которого собрано. Несовпадение = стоп-деплой.

5. **Тег на задеплоенный build.** Каждый задеплоенный артефакт получает immutable git-tag (`cpe-build72`, `mdm-server-<sha>`). Отвечает на «что реально работает в проде?» без гадания.

6. **Provenance-запись.** Логировать: какой commit/tag → куда задеплоен → когда → результат verify-no-break (deploy-лог / паспорт). Дрейф становится обнаружимым.

## DoD
Задача не «done», пока:
- задеплоенное == запушенному, тегированному git-ref;
- нет local-only источника задеплоенного кода;
- verify-no-break пройден до/после деплоя.
