# Стандарт: Fable — только по явному указанию

**Статус:** обязательный · **Применимость:** все проекты, любой выбор модели — для сессии, координатора, агента ядра, субагента, `agent()` в workflow, `model`-override. Не действует, только если владелец в задаче явно назвал Fable.
**Источник:** директива владельца 2026-09-14.

## Правило
1. **Fable без явного указания модели не использовать.** Ни как модель сессии, ни как ярус субагента, ни «на всякий случай для важного».
2. **«Самая крутая», «самая мощная», «самая-самая», «флагманская», «лучшая» = Opus.** Такие слова — не явное указание на Fable. Везде, где правила `.profi` требуют «самую свежую флагманскую» (Шаг 0 `scenarios/session-start.md`, решающий ярус), читать как Opus.
3. **Явное указание** — это когда названа сама модель: «возьми Fable», «на Fable», `claude-fable-*`. Только тогда Fable допустима.
4. **Говорить об этом прямо.** Если задача или бриф подталкивают к Fable без её названия — ответить формулировкой:
   > «Fable дорогая. Opus достаточно умна для любых задач. Использование Fable возможно, если явно указать, что нужна она.»

## Почему
Fable дорогая, а Opus справляется с любыми задачами решающего яруса. Слова вроде «самая мощная» раньше приводили к выбору Fable по умолчанию.
